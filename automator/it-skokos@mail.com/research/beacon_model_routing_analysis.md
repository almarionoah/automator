## 2. Dynamic Routing Architecture & Cost-to-Delight Matrix

| Tier / Task Type | Candidate Model | Avg. Cost / 1k In+Out Tokens | Perceived Latency | Human-Feel Score (1-10) | Routing Condition |
|---|---|---|---|---|---|

## 3. Findings & UX Optimization Strategy
1. **Threshold-Based Cascading**: Route 72% of standard platform interactions to Tier 2 models. This preserves tactile snappiness while reducing API spend by an estimated 58% compared to direct Tier 1 defaults.
2. **Sentiment & Frustration Escalation**: Inject dynamic switches to Tier 1 when hesitation or friction is detected in the UI stream, ensuring empathetic depth precisely when users feel vulnerable.
3. **F2F Service Synthesis**: Pre-cache deterministic operational data via Tier 3 to eliminate interface stalls during customer-facing meetings.

## 4. Conclusion
Adhering to our fiscal framework from the **Company Document**, dynamic routing allows Beacon API to maintain a premium, soulfully responsive user journey while drastically curbing marginal inference costs.
