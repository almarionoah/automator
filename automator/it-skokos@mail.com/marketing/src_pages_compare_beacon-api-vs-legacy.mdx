## 2. Quickstart Implementation

```typescript
import { BeaconClient } from '@skokos/beacon-sdk';

// Initialize hybrid event listener for SaaS & F2F dispatch
const beacon = new BeaconClient({
  apiKey: process.env.SKOKOS_BEACON_KEY,
  f2fSync: true,
});

await beacon.stream.subscribe('dispatch.f2f.checkin', (event) => {
  console.log(`Synced attendee ${event.userId} at node ${event.locationId}`);
});
```
